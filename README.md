# sample-kuropug-skill

黒パグ式スキルの最小実装です。資料を読んで終わらず、根拠を保ったまま「何が書かれているか」「何に使えるか」「次に何をするか」へ変換します。

## できること

- 論文、公式文書、README、記事などから重要な主張を抽出する
- 原文の事実とAIの解釈を分離する
- 出典位置を残す
- 自分の作業へ転用できる点と、転用できない点を分ける
- 最後に具体的な次の行動を提示する

単なる要約ではなく、参考資料を実際の設計や作業へつなぐためのサンプルです。

## 最小構成

```text
sample-kuropug-skill/
├── SKILL.md
└── README.md
```

`SKILL.md`だけでもスキルとして成立します。このリポジトリでは、実用時の分離例として`references/`、機械的な確認例として`scripts/`、試験用に`tests/`も収録しています。

## 実用構成

```text
sample-kuropug-skill/
├── SKILL.md
├── README.md
├── references/
│   ├── output-format.md
│   └── review-checklist.md
├── scripts/
│   └── validate_brief.py
└── tests/
    ├── fixtures/
    │   ├── valid-brief.md
    │   └── invalid-brief.md
    └── test_validate_brief.py
```

## 導入

### Codex

このリポジトリをダウンロードまたはcloneし、スキル用ディレクトリへ配置します。

```bash
git clone https://github.com/Blackpug-LLM48P/sample-kuropug-skill.git
```

環境によってスキルの配置場所や導入方法は異なります。分からない場合は、現在の画面をスクリーンショットでGPTへ渡し、「このリポジトリをスキルとして導入したい。次の操作を一つずつ教えて」と依頼してください。

### Claude Code

Agent Skills形式を読み込める場所へ、このディレクトリをそのまま配置します。製品固有の場所や仕様は更新されるため、導入時点の公式資料も確認してください。

## 使い方

資料、URL、PDFなどと一緒に、次のように依頼します。

```text
この論文から、長時間動作するAIエージェントの設計に使える原則を抽出して。
```

```text
このREADMEを調べて、自分の画像生成スキルへ転用できる部分と、そのまま使えない部分を分けて。
```

明示的に呼び出せる環境では、スキル名`source-to-action-brief`を指定できます。自動選択に対応する環境では、資料から根拠付きの実用ブリーフを求める依頼で使用されます。

## 検証

出力ファイルの基本構造は、同梱スクリプトで確認できます。

```bash
python3 scripts/validate_brief.py tests/fixtures/valid-brief.md
python3 -m unittest discover -s tests
```

この検査は必須見出しと出典位置の有無を確認するだけです。内容の正しさや引用元との一致は、人間または資料を読めるAIが別途確認する必要があります。

### 長文資料で回答が空になる場合

一部のモデルや実行環境では、長文資料を高い推論設定で処理すると、推論だけで出力上限を使い切り、最終回答が空になることがあります。本スキルは、網羅的な内部計画よりユーザーへ返す回答を優先し、上限が厳しい場合は短い部分回答を返すよう指示しています。

環境側で設定できる場合は、次も確認してください。

- 最終回答と推論で同じ`max_tokens`を共有していないか
- 長文入力に対して出力上限が小さすぎないか
- 高い推論設定が本当に必要か
- 一度に全文を処理せず、章単位へ分割すべきか

## 黒パグ式で重視すること

1. 元資料とAIの提案を混ぜない
2. 出典位置を残す
3. そのまま転用できない部分も書く
4. 作って終わらず、出力を検査する
5. 実際の失敗を次の版へ反映する

> 資料を読み込ませました。要約されました。わあ！すごい！  
> まだ何も作っていません。

## 注意

- 外部資料の利用条件、著作権、ライセンスを確認してください。
- 非公開資料、個人情報、APIキーなどを公開AIへ送らないでください。
- コミュニティスキルにスクリプトが含まれる場合は、実行前に内容と権限を確認してください。
- 本リポジトリの検証スクリプトはファイルを読み取るだけで、ネットワーク通信やファイル変更は行いません。
