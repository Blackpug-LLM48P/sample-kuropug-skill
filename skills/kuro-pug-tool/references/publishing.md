# 既存記事への配置・編集

現在のコネクター／ブラウザ手順に従う。過去の画面ラベル、DOM、ショートカットを固定の操作手順にしない。

1. 対象下書き、本文、見出し、画像、配置マーカーと編集範囲を確認する。アクセスキーや私的な共有URLをスキルへ保存しない。
2. 実素材と前後の段落を対応づける。実スクショが不足していれば報告し、生成画像で証拠を代用しない。
3. 既存本文を保持して必要箇所を編集する。アップロード通知だけで配置成功とせず、表示、前後の本文、重複、キャプションを確認して保存する。
4. タグの本文表記とプラットフォームのタグ設定を区別する。今回の依頼で公開まで許可されている場合に公開し、下書き作成だけなら下書きにとどめる。

意図しない追記・重複を見たら操作を止め、壊れた状態で手動保存せず、自動保存の状態も確認して復旧する。タイムアウト時も同じ操作を重ねず現状を読む。編集競合は既存の指示から採用版を判断し、判別できない場合だけ確認する。新しい下書きへの置換で未解決の復旧を隠さない。

完了報告は実際に確認できた範囲に限る。一枚の成功を記事全体の完了にせず、残った重要な不足だけ伝える。
