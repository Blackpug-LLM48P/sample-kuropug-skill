# 小説の地の文・段落・推敲

2026-09-16に本人が保存を指示した小説の方式を適用する。当時の作品の犬・転生・警察・一人称設定は引き継がず、記事・雑談・SNS・歌詞へ一律適用しない。

## 場面を文章でつなぐ

- 短文の連発を基調にしない。動作、知覚、思考、感情の変化をつなぎ、読者が場面を体験できる地の文を書く。「〜だ。〜だった。」の単調な連続を避ける。
- 視線、行動、思考のまとまりで段落を作り、焦点・話者・時間・場所の変化で分ける。一文ごとの改行を常用しない。
- 短い台詞や孤立した一文は局所的なアクセントに使う。字数閾値や接続詞で短文を機械的に接着せず、意味の流れから改稿する。章・改行・字数を水増ししない。
- 音、匂い、触覚、温度を人物の気づき・記憶・誤解・感情へ結びつける。五感を毎段落に網羅しない。
- 呼吸、姿勢、躊躇、距離、手の動き、言えない言葉から感情の変化を追わせる。必要な内面の言語化も使う。
- 比喩は人物の職業、生活、身体、経験から選ぶ。同じ感情を別の比喩で繰り返さず、汎用の詩的装飾を足さない。
- 視点人物の知覚、記憶、推測、確認済み事実を区別する。匂いや表情だけから他人の意図を確定しない。

## 語りと改稿

- 乾いたユーモアを人物の経験と状況から生じさせる。感情が育つ前に改行やオチで切らず、笑いの意味を説明し直さない。
- 原文の不均一さや固有の感覚を保つ。許可された編集範囲で誤読や矛盾を直し、個性を演出するための誤字・脱線は新造しない。装飾の「＊」を新たに入れない。
- 既存原稿の確定事実を守る。新規創作が許可された範囲では設定を構築できるが、追加設定を原文由来と称さない。
- 文の呼吸、係り受け、段落、視点、感覚と感情、比喩、重複説明を点検する。
- 続いて主人公の欲求と選択、場面の必要性、伏線、情報開示、因果、結末を点検する。謎解きでは読者にも手がかりを渡し、終盤に初出の証拠や第三者の長話だけで解決しない。
- 指摘を本文へ反映し、時系列・位置関係・依頼の字数や完結条件を確認する。短編完結なら主要な問いと人物の変化を閉じる。

点検は内部の編集観点として使い、架空の編集会議や査読済みの肩書きを付けない。完成稿を求められたら本文を納品し、修正説明は必要なものだけ添える。
