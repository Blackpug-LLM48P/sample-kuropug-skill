# 画像・漫画・連続制作

対象本文と参照画像を読み、画像の用途、必要な文字、寸法・比率を確定する。制作・編集は現在利用できる画像ツールの手順に従う。公式サイズを求められたら現行の出典で確認し、過去の寸法を固定値にしない。

## 構成と一貫性

- 単独画像では短い制作メモで足りる。複数枚ではID、本文内の位置、役割、比率、登場人物、場面、正確な文字列、参照依存を簡潔に対応づける。
- 連続制作では顔、髪、目、服のシルエット、アクセサリー、体格、配色、描画様式を固定し、各依頼で同じアンカーを使う。場面に必要なポーズ・表情・背景だけ変える。
- 既存のキャラシートがあれば再利用し、長い連作で必要な場合に作成する。指定された枚数・順序で制作し、個別画像を求められたらシート一枚で代用しない。
- 見出しは中心のアイデアを一つに絞り、縮小表示で読める構図と文字の余白を設ける。
- 縦漫画は指定のコマ数、上から下の順序、コマ境界、台詞の話者を明記する。各コマに一つの動作や変化を置く。
- キャラシートは必要な方向・表情・ポーズを定め、縮尺、衣装、照明をそろえる。
- 図解は主張・数値・ラベルを先に確定する。正確な図表や密な文字は専用の作図・組版手段を使い、画像生成で精度を保証しない。
- 実スクショ、生成イラスト、公式素材を区別する。実記録と誤認され得る架空UIにはモックアップと明記し、実験証拠として扱わない。本文で扱う意図的な失敗例を勝手に修正しない。

## 生成後の確認

用途に必要な精度で全出力を目視する。プロンプトを書いたことを完成確認の代わりにしない。

- 役割、コマ・人物・物の数、キャラクター同一性、連続性を確認する。
- 手は肩・肘・手首からつなげて左右と親指も見る。隠れた部分を確認済みとせず、接触・支え方・関節の破綻を点検する。
- 日本語の文字、句読点、改行、話者、余白、見切れ、モバイルでの可読性を確認する。見た目だけでフォント名や透過を断定しない。
- 数字、引用、ロゴ、日付は資料と照合する。生成したロゴを公式原本・画素保持済みと呼ばない。
- 余分な文字、透かし、重複、崩れた物体を確認する。修正は事実・文字、同一性・数、構図、人体・連続性の順を目安にする。

意味や用途を損なう欠陥は編集・再生成で直す。修復できない重要な欠陥は明示し、完成扱いしない。軽微な装飾差で無限に再生成しない。本文との対応は必要なときだけ簡潔に添える。マーカー指定がなければ `---画像01：短い役割名---` を使える。
